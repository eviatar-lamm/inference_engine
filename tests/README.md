# GPT-2 tokenizer comparison

The 35 English/ASCII cases in `tokenizer_reference.json` contain exact token IDs
generated by [OpenAI's official GPT-2 encoder](https://github.com/openai/gpt-2/blob/9b63575ef42771a015060c964af2c3da4cf7c8ab/src/encoder.py).
They cover empty input, sentences, case, contractions, punctuation, numbers,
letter/digit boundaries, underscores, repeated text, whitespace, and ASCII controls.
Only `encode` is tested; `decode` has no implementation yet.

From the repository root, with `vocab.json` and `merges.txt` in `models/gpt2`:

```sh
cmake -S . -B build-tests -DBUILD_TESTING=ON
cmake --build build-tests --target tokenizer_tests
ctest --test-dir build-tests -R tokenizer --output-on-failure
```

The C++ test compares every token ID, reports each failed input with its expected
and actual IDs (or exception), and exits unsuccessfully if any case fails.
Normal test runs need neither Python nor network access nor model weights.

To independently verify the reference using the unmodified official Python code,
install its `regex` dependency in your Python environment, then run:

```sh
python3 -m pip install regex
curl -fsSL https://raw.githubusercontent.com/openai/gpt-2/9b63575ef42771a015060c964af2c3da4cf7c8ab/src/encoder.py -o /tmp/gpt2-encoder.py
python3 tests/check_tokenizer_reference.py /tmp/gpt2-encoder.py
```

Add `--write` to regenerate the expected IDs after changing inputs. The fixture
records the source URL and SHA-256 hashes of the encoder, vocabulary, and merges;
verification checks these as well as the IDs. Use `--model-dir` to select another
directory containing the GPT-2 tokenizer files.
